6.1

RF Bug / Hidden Camera Detector

Perangkat untuk mendeteksi perangkat penyadap (bug) dan kamera tersembunyi di ruangan sebelum pertemuan sensitif berlangsung. Menggabungkan tiga metode: RF emission scanning, deteksi lensa kamera via inframerah, dan analisis anomali sinyal. Wajib dimiliki tim counter-surveillance sebelum briefing atau negosiasi penting.
🔧 Hardware
ESP32 + modul RF detector TL-07H (1MHz–6GHz) + sensor IR untuk lens detection + OLED display + buzzer + baterai LiPo 2000mAh
💻 Software
Custom firmware: RF threshold alert, sweep mode, sensitivity adjustment, logging ke MicroSD
⚙️ Fungsi Utama
Sweep RF 1MHz–6GHz dan alert jika ada pemancar aktif • Deteksi lensa kamera via pantulan IR (efektif untuk kamera tersembunyi non-WiFi) • Mode visual: bar graph kekuatan sinyal per frekuensi • Audio alert berbeda untuk RF vs kamera • Sensitivity adjustable untuk menghindari false positive dari perangkat resmi
🎯 Use Case Operasional
Sweep ruang rapat sebelum diskusi sensitif • Deteksi bug di kendaraan dinas • Counter-surveillance sebelum operasi lapangan • Pemeriksaan kamar hotel untuk delegasi atau pimpinan VIP
ℹ️ Deteksi kamera pasif (tanpa WiFi/RF) memerlukan kondisi pencahayaan gelap. Gabungkan dengan pemeriksaan fisik manual untuk hasil optimal.

6.2

Non-Linear Junction Detector (NLJD) Sederhana

Versi terjangkau dari NLJD profesional — alat yang memancarkan sinyal microwave dan mendeteksi harmonic response dari semikonduktor tersembunyi (transistor, IC) meski perangkat dalam kondisi mati. Ini cara paling andal mendeteksi bug elektronik yang sedang tidak aktif atau dalam mode sleep. Perangkat NLJD profesional komersial berharga ratusan juta — versi ini membangun fungsi inti dengan sepersepuluh biaya.
🔧 Hardware
HackRF One + antena probe directional custom (horn antenna) + RPi 4 + LNA low-noise amplifier + shielded coax cable + display portable
💻 Software
GNU Radio: transmit 920MHz, receive & analyze 1840MHz (2nd harmonic) + 2760MHz (3rd harmonic), threshold detection, anomaly mapping
⚙️ Fungsi Utama
Memancarkan sinyal probe 920MHz ke permukaan yang diinspeksi • Mendeteksi harmonic emission pada 1840MHz dan 2760MHz yang hanya dihasilkan semikonduktor • Response lebih kuat pada komponen aktif (IC, transistor) vs material pasif (logam, dinding) • Sweep permukaan dinding, furnitur, benda dekorasi, colokan listrik • Log peta area dengan posisi anomali tertandai
🎯 Use Case Operasional
Pemeriksaan mendalam ruangan VIP, SCIF darurat, atau ruang negotiation • Deteksi bug yang sedang sleep atau off (tidak terdeteksi RF sweep biasa) • Verifikasi lanjutan setelah RF/IR sweep awal tidak menemukan apapun • Pemeriksaan furnitur atau hadiah yang diterima dari pihak tidak dikenal
⚠️ Memerlukan kalibrasi dan pengalaman operator untuk membedakan false positive (komponen listrik normal) dari target nyata. Direkomendasikan training sebelum deployment.
Budget
Rp 3.500.000
Waktu Build
2–3 Minggu
Metode
Harmonic Detection
Deteksi
Perangkat ON maupun OFF
6.3

Spectrum Anomaly Monitor (Passive Room Guard)

Unit yang dipasang permanen di ruangan sensitif untuk monitoring RF berkelanjutan 24/7. Secara otomatis mempelajari baseline spektrum RF normal ruangan dalam 24 jam pertama, lalu memberikan alert real-time jika muncul sinyal baru yang tidak dikenali — indikasi pemasangan bug baru atau kehadiran perangkat asing. Tidak memerlukan operator aktif.
🔧 Hardware
RTL-SDR v3 + Raspberry Pi Zero 2W + antena omnidirectional indoor + powered via USB (selalu terhubung listrik)
💻 Software
Custom Python: spectrum baseline learning (FFT averaging 24 jam), anomaly detection (isolation forest ML), Telegram bot alert, web dashboard history
⚙️ Fungsi Utama
Belajar baseline spektrum RF unik ruangan dalam 24 jam pertama • Alert otomatis jika ada sinyal RF baru atau abnormal muncul • Dashboard web dengan history spektrum 7 hari terakhir • Notifikasi via Telegram bot dengan screenshot spektrum anomali dan timestamp • Laporan harian otomatis: kondisi normal atau ada anomali
🎯 Use Case Operasional
Perlindungan pasif ruang kerja pejabat penting secara 24/7 • Deteksi dini aktivitas surveilans pihak lawan • Monitoring otomatis tanpa butuh operator aktif setiap saat • Deteksi jika ada yang memasang perangkat baru saat ruangan kosong
ℹ️ Pasang dan lupakan — berjalan headless tanpa monitor. Alert langsung masuk Telegram kapanpun anomali terdeteksi, siang maupun malam.

RFID/NFC Multi-Protocol Cloner

Perangkat portabel untuk membaca, menganalisis, dan mengkloning kartu akses RFID/NFC yang digunakan pada sistem access control gedung, kunci kartu hotel, dan kartu identitas. Mendukung berbagai protokol dari kartu murah (EM4100) hingga kartu semi-modern (MIFARE Classic) yang masih sangat luas digunakan di Indonesia.
🔧 Hardware
PN532 NFC module + ACR122U USB reader + ESP32 (controller) + OLED display + baterai 2000mAh + kartu blank RFID/NFC (125kHz + 13.56MHz)
💻 Software
libnfc, nfc-tools, Proxmark3-compatible scripts, custom clone writer firmware, MIFARE Classic nested attack tool
⚙️ Fungsi Utama
Read dan decode UID kartu EM4100, HID Prox 125kHz • Read MIFARE Classic (1K/4K), MIFARE Ultralight, NTAG21x • Crack MIFARE Classic sector key via nested authentication attack • Tulis UID dan data ke kartu blank • Emulasi kartu via NFC-enabled Android (mode virtual card)
🎯 Use Case Operasional
Physical penetration testing akses gedung target • Clone kartu akses personel selama operasi proximate • Security assessment kelemahan sistem access control instansi klien • Entry ke area terbatas dalam operasi fisik yang memiliki legal basis
⚠️ MIFARE Classic masih sangat luas dipakai di gedung Indonesia. MIFARE DESFire AES memerlukan teknik lebih lanjut dan tidak tercakup di sini.

Dirancang untuk disamarkan dalam tas, clipboard, atau objek sehari-hari. Data tersimpan otomatis dan diunduh via Bluetooth ke smartphone operator.

💻 Software

Pengumpulan UID kartu akses target dalam operasi social engineering jarak dekat • Reconnaissance sistem access control sebelum physical entry • Konfirmasi jenis kartu yang digunakan di fasilitas target
⚠️ Hanya digunakan dalam operasi yang memiliki legal basis resmi. Range baca 125kHz lebih jauh dibanding 13.56MHz — bergantung pada antena dan jenis kartu target.

8.1

Mobile Device Triage Unit

Appliance untuk akuisisi data cepat dari perangkat mobile yang diperoleh secara fisik di lapangan. Melakukan ekstraksi data tanpa mengubah state perangkat (forensically sound), mendukung Android via ADB. Hasil akuisisi dalam format yang kompatibel dengan tools forensik standar (Autopsy, Cellebrite-compatible image format).
🔧 Hardware
Mini PC / RPi 4 + USB hub + set kabel (USB-C, Lightning, Micro-USB, USB-A) + SSD eksternal 1TB + display portable 13"
💻 Software
ADB + adb-dump automation scripts, Android backup extractor, Frida-server untuk bypass, Autopsy forensic suite lokal, metadata analyzer (ExifTool)
⚙️ Fungsi Utama
Full backup Android via ADB (aplikasi, chat, foto, dokumen, kontak) • Ekstraksi database WhatsApp, Telegram (jika tidak full-encrypt) • Dump call log, SMS, browser history • Analisis metadata foto: GPS location, timestamp, device model • Generate hash SHA-256 per file untuk chain of custody • Report HTML otomatis dengan daftar artefak ditemukan
🎯 Use Case Operasional
Triage cepat perangkat tersangka yang diperoleh di lapangan sebelum dibawa ke lab • Preservasi bukti digital sebelum perangkat dimatikan atau melakukan remote wipe • Rekonstruksi timeline aktivitas tersangka dari data perangkat • Ekstraksi kontak dan jaringan komunikasi untuk analisis lanjut
ℹ️ Android dengan USB debugging aktif paling mudah diakuisisi. Full-disk encryption Android modern (versi 10+) membatasi akses data at-rest. iOS sangat terbatas tanpa jailbreak.

1.5 Minggu

8.2

Portable Disk Imager & Write Blocker

Tool forensik untuk membuat disk image identik dari storage media yang disita (HDD, SSD, USB flash drive, MicroSD) tanpa memodifikasi data asli. Write blocker hardware/software memastikan tidak ada data yang tertulis ke media sumber — menjaga integritas barang bukti dan rantai kustodi untuk keperluan hukum.
🔧 Hardware
RPi 4 / Mini PC + USB 3.0 hub + hardware write blocker (FastBloc USB atau equivalen) + SSD NVME 2TB (storage image) + display portable
💻 Software
Guymager (forensic imager GUI), dcfldd dengan progress bar, md5sum/sha256sum otomatis, Sleuth Kit (preview file system), laporan akuisisi auto-generate
⚙️ Fungsi Utama
Disk imaging kecepatan hingga 150MB/s (SSD-to-SSD) • Format image E01/raw (kompatibel Autopsy, FTK, Cellebrite) • Hash MD5 + SHA-256 otomatis sebelum dan sesudah imaging untuk verifikasi integritas • Preview isi file system tanpa mounting penuh (tidak mengubah atime) • Laporan akuisisi PDF otomatis: timestamp, operator, hash, ukuran media
🎯 Use Case Operasional
Akuisisi forensik HDD/SSD dari komputer tersangka • Imaging USB flash drive atau MicroSD barang bukti • Preservasi bukti digital sesuai standar yang dapat dipertahankan di persidangan • Duplikasi media untuk analisis paralel tanpa risiko pada media asli
ℹ️ Format E01 + hash SHA-256 adalah standar internasional untuk bukti digital. Hash yang cocok sebelum/sesudah imaging membuktikan integritas di persidangan.

Appliance full packet capture untuk merekam dan menganalisis semua traffic jaringan dalam sesi investigasi. 💻 Software
Arkime (full packet capture + indexing), Zeek IDS/NSM (protocol parser), Elasticsearch lokal, Kibana dashboard, NetworkMiner (artifact extraction)
⚙️ Fungsi Utama
Full packet capture 100/1000Mbps ke disk dengan indexing • Auto-parsing protokol: HTTP, DNS, TLS metadata, SMTP, FTP, SMB, Kerberos • Rekonstruksi file yang ditransfer (gambar, dokumen, executable) otomatis • Alert koneksi ke IP/domain berbahaya (threat intel feed lokal) • Query interaktif via Arkime web UI — tidak butuh command line • Export PCAP per sesi untuk analisis lanjut
🎯 Use Case Operasional
Investigasi insiden keamanan jaringan instansi • Rekonstruksi aktivitas tersangka di jaringan internal • Identifikasi dan bukti data exfiltration • Monitoring jaringan pasca-kompromi untuk deteksi persistence • Analisis malware C2 communication dari sampel yang ditangkap
ℹ️ SSD NVME 1TB menampung 8–24 jam full traffic 100Mbps. Kapasitas expandable dengan SSD eksternal USB 3.0. Arkime web UI sangat intuitif untuk investigator non-teknis.

Off-Grid Encrypted Mesh Radio (LoRa)

Jaringan komunikasi teks terenkripsi end-to-end berbasis LoRa yang beroperasi tanpa infrastruktur seluler, WiFi, atau internet. Ideal untuk koordinasi tim di area blank spot sinyal, atau situasi di mana komunikasi via HP dianggap tidak aman atau sedang dimonitor. Setiap node berfungsi sebagai relay otomatis, memperpanjang jangkauan secara mesh.
🔧 Hardware
ESP32 + LoRa module SX1276 (433MHz atau 915MHz) + OLED display 1.3" + keyboard thumb mini opsional + baterai LiPo 3000mAh + antena fiberglass 5dBi
💻 Software
Meshtastic firmware (open source, AES-256 encrypted, battle-tested), custom channel config, silent mode (no LED), store-and-forward relay, GPS position sharing opsional
⚙️ Fungsi Utama
Teks terenkripsi AES-256 end-to-end antar semua node • Range 5–15km per hop di terrain terbuka, extendable via relay node • Setiap node otomatis menjadi repeater untuk node lain (mesh) • Tidak butuh SIM card, WiFi, atau internet apapun • GPS position sharing opsional: semua anggota tim terlihat di peta yang sama • Daya tahan baterai 3–7 hari tergantung traffic
🎯 Use Case Operasional
Koordinasi tim operasi di area blank spot sinyal seluler • Komunikasi aman saat HP dianggap sedang dimonitor atau tidak aman • Backup komunikasi darurat jika jaringan seluler down atau jamming • Tracking posisi tim lapangan secara realtime tanpa internet
ℹ️ Meshtastic sudah digunakan komunitas taktis dan emergency responder global. Enkripsi AES-256 end-to-end — bahkan node relay tidak dapat membaca isi pesan.

10.3

Hardware Security Key (DIY FIDO2 / TOTP Token)

Token keamanan hardware berbasis ESP32-S3 yang mengimplementasikan FIDO2/WebAuthn dan TOTP untuk autentikasi dua faktor yang tidak bisa di-phish. Melindungi akun operasional dari credential theft bahkan jika password bocor. Dibuat sendiri = lebih terpercaya dari token komersial yang berpotensi memiliki supply chain backdoor.
🔧 Hardware
ESP32-S3 + USB-C connector (USB HID mode) + kapasitif touch sensor (tombol fisik) + LED RGB status + Casing epoxy resin kecil (ukuran USB drive)
💻 Software
Custom firmware: FIDO2/CTAP2 compliant (USB HID), TOTP generator RFC 6238, flash encryption ESP32 (secure element emulation), anti-tamper detection, wipe otomatis setelah 10 gagal
⚙️ Fungsi Utama
FIDO2 hardware token untuk login akun tanpa SMS OTP yang rentan SIM-swap attack • TOTP 6-digit generator untuk semua layanan 2FA standard (Google, Microsoft, dll) • Pure USB HID — tidak ada koneksi wireless (tidak bisa di-sniff atau di-jam) • Wipe otomatis setelah 10 percobaan PIN gagal (brute-force protection) • Firmware open-source: dapat diaudit sendiri untuk verifikasi tidak ada backdoor
🎯 Use Case Operasional
Perlindungan akun operasional instansi dari phishing dan SIM-swap attack • Authentication kuat untuk akses server, VPN, dan platform kritikal • Key management untuk sistem enkripsi komunikasi operasional • Distribusi ke personel lapangan dengan biaya jauh lebih rendah dari YubiKey komersial
ℹ️ Jauh lebih murah dari YubiKey komersial (Rp 800rb+) dengan keunggulan utama: source code dapat diaudit penuh, tidak ada supply chain risk dari vendor asing.
Budget / unit
Rp 150.000
Waktu Build
3 Hari
